# Capture the Flag: Systems of Equations (3-1 Practice)

A browser game for practicing the 3-1 worksheet on solving systems of equations by graphing.
Students solve problems to move their runner across the field and capture the other team's flag.

Open `index.html` in a browser to play.

## Modes

- **Two teams, one screen** – Red and Blue take turns on a shared or projected screen.
- **Solo practice** – race a rival runner that moves every 40 seconds.
- **Live class game** – everyone plays on their own device with a shared scoreboard and teacher controls.
  This mode needs the hosted Claude artifact (it uses the artifact's shared database), so it shows as
  unavailable when `index.html` is opened on its own.
